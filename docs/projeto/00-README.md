# Projeto - ERP EVOK ÁUDIO

## Estrutura dos Documentos

```
docs/projeto/
├── 00-README.md               <- Este índice
├── 01-PLANO.md                <- Plano do projeto: arquitetura, stack, roadmap
├── 02-PLANO_INDUSTRIAL.md     <- Plano industrial: perfil da empresa, módulos, escala
├── 03-CRONOGRAMA_FASES_2_3.md <- Cronograma e checklist das Fases 2 e 3
└── 04-USE_CASES.md            <- Casos de uso: atores e fluxos (UC-01, UC-02...)
```

Documentos de planejamento e escopo do projeto — não são documentação funcional de
uma área da fábrica (essa fica em `docs/<área>/`), e sim sobre o projeto de software
em si: o que construir, em que ordem, e por quê.
